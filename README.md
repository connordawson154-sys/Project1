# PoundPlan prototype

A mobile-friendly, manual-entry UK budgeting app inspired by zero-based budgeting.

## Run it
- Open `index.html` in a modern browser, or
- Deploy the folder as a static site (for example, with GitHub Pages or Netlify).

## Current features
- GBP budgeting and monthly budgets
- Manual income and expense/savings transactions
- Category allocations and unallocated-income calculation
- Debt snowball tracker
- Savings goals
- Baby Steps progress tracker
- JSON backup export/import

## Important limitations
This is an early prototype. Data is stored in local browser storage and does not sync between devices. It has no login, shared budgets, server database, or production security. Do not use it to store data for public users yet. Before public release, add authentication, server-side access controls, encrypted transport, privacy policy, data deletion/export controls, testing, and secure hosting. Review Dave Ramsey-related branding and content before commercial distribution; use your own branding and original wording.
